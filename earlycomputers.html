Digital Hauntology

2026-06-12

Hauntology, specifically, digital hauntaology is what I can only describe as dead code. Where code runs without a human audience, a game unplayed, leftover code running somewhere in an unused server. An easily seen example is how there are more dead users on facebook than alive ones, and as we advance technology faster and faster, build more and more, more dead code runs, without purpose and not enough hands to delete it all. Its superliminal in a sense, like the backrooms, like the feeling of being in a large weird room with no one else and no sound other than yourself. We build more and more servers and more and more code, and AI which requires more servers and codes for us requiring more servers. The modern age is not "ant-hauntology," its the most pro hauntology we have ever seen technology.
